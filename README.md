# Laakmann Book Tasks (TypeScript)

Solutions to algorithmic problems from *Cracking the Coding Interview*,  
implemented in **TypeScript** with a focus on **clarity, trade-offs, and engineering thinking**.

The goal of this repository is not to collect as many solutions as possible, but to:
- systematize common algorithmic patterns;
- document reasoning and decision-making;
- keep solutions in an interview-ready, easy-to-review format.

---

## 📦 Tech Stack

- TypeScript (strict mode)
- Node.js
- Jest (tests, incremental)
- ESLint / Prettier (planned)
- GitHub Actions CI (planned)
